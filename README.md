# საგამოცდო ისტორიული ატლასი

ისტორიის რუკები და ეროვნული გამოცდების ტესტები აბიტურიენტებისთვის — საქართველოს და მსოფლიო ისტორია,
შეფასებისა და გამოცდების ეროვნული ცენტრის (NAEC) საგამოცდო პროგრამის 11 თემის მიხედვით.

*A study site for the Georgian Unified National Exam in history: 104 interactive historical maps with Georgian labels,
and the official history exam papers of 2016–2026 (37 variants) as interactive tests with timer, scoring and answer keys.*

## რა არის საიტზე

**რუკები** (`#`)
- 104 ინტერაქტიული რუკა ერთ სტილში, გამოცდის რუკების პირობითი ნიშნებით (ტერიტორიები, ლაშქრობები, ბრძოლები, ქალაქები).
- თითო რუკაზე: მოკლე ახსნა, მთავარი ფაქტები, „დაიმახსოვრე“, როგორ ამოვიცნოთ რუკა, რეალური ისტორიული რუკა (Wikimedia Commons).
- ციფრების რეჟიმი (სახელები იმალება, როგორც გამოცდაზე), ძებნა, ფილტრები, „გამოცდაზე ნანახი“ თემები ბმულით შესაბამის ტესტზე.

**ტესტები** (`#tests`)
- ისტორიის ერთიანი ეროვნული გამოცდის 37 ვარიანტი: 2020–2026 (ძირითადი და დამატებითი სესიები, 60 ქულა) და 2016–2019 (70 ქულა).
- ტესტის არჩევისას ფანჯარა: **დაწერა** — საგამოცდო დროით (2 სთ 40 წთ), დროის გარეშე ან საკუთარი დროით; ან **პასუხების ნახვა**.
- წერისას: პასუხების ფურცელი, კითხვის მონიშვნა, პაუზა (არა-საგამოცდო რეჟიმში), კლავიატურა (1–4, ←/→, F); პროგრესი ინახება ბრაუზერში.
- შედეგი: ტესტური კითხვები და ქრონოლოგია ფასდება ავტომატურად; ღია კითხვებთან ჩანს შენი პასუხი და NAEC-ის შეფასების სქემა — ქულას თავად ანიჭებ.
- რუკები, ილუსტრაციები და ბრძოლის სქემები ამოჭრილია ორიგინალი PDF-ებიდან; გადიდება თითებით ან ბორბლით.

**მოწყობილობები**: ტელეფონი (ქვედა ნავიგაცია, bottom sheet ფანჯრები), პლანშეტი, კომპიუტერი, დიდი ეკრანი; მუქი/ღია თემა;
დაყენება როგორც აპლიკაცია (PWA) და ოფლაინ მუშაობა; ბეჭდვა.

## სტრუქტურა

```
index.html              საიტი (სტატიკური; მუშაობს file://-ითაც)
assets/app.js           რუკები, მარშრუტები, ნავიგაცია, თემა
assets/tests.js         ტესტების განყოფილება (კატალოგი, ფანჯარა, წერა, შედეგი, პასუხები)
assets/style.css        დიზაინი და ყველა ზომის ეკრანის განლაგება
data/catalog.js         რუკების კატალოგი;  data/maps/<id>.js — თითო რუკის მონაცემები
data/tests/index.js     ტესტების კატალოგი; data/tests/<id>.js — თითო ტესტი (კითხვები, პასუხები, სქემა)
img/real/               რეალური რუკები (Wikimedia Commons)
img/tests/              ტესტების რუკები და ილუსტრაციები
manifest.webmanifest, sw.js   აპლიკაციად დაყენება და ოფლაინ ქეში
_build/                 მონაცემების აწყობის სკრიპტები (Node.js)
```

## გაშვება

ნებისმიერი სტატიკური სერვერი პროექტის საქაღალდეზე, მაგ.:

```
npx serve .
```

ან უბრალოდ გახსენი `index.html` ბრაუზერში (სერვის-ვორკერი და ოფლაინ რეჟიმი მხოლოდ http(s)-ზე მუშაობს).

## მონაცემების აწყობა

```
cd _build && npm install
node build.mjs                 # რუკები: src/bNN-*.mjs -> data/maps, data/catalog.js
node tests/download.mjs        # ტესტები: NAEC-ის PDF-ები (tests/manifest.mjs)
node tests/extract.mjs         # PDF -> ტექსტი პოზიციებით
node tests/parse.mjs           # ანგარიში და შემოწმება;  node tests/pretty.mjs <id> — წასაკითხი ამონაწერი
node tests/build.mjs           # data/tests/*.js, img/tests/*.webp
```

ხელით შესწორებები (დეფისები, სქემის შეცდომები) — `_build/tests/fixes.mjs`. სამუშაო ჩანაწერები — `_build/PROGRESS.md`.
